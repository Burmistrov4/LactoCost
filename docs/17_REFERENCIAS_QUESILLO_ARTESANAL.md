## 3. Lectura correcta

1. La referencia artesanal de US$10/kg es una **pista histórica de publicación pausada**, no el precio medio vigente de Valencia.
2. Las referencias de Cremosillo son industriales y minoristas; no permiten deducir el precio de venta artesanal ni el costo de fabricación.
3. El precio por kg solo es comparable si se confirma peso neto real, inclusión de envase, sabor, canal, fecha, IVA y entrega.
4. No se debe promediar la publicación artesanal con Cremosillo para obtener un “precio promedio de quesillo”: pertenecen a canales y niveles de producto distintos.
5. Aún no existe evidencia suficiente para declarar un rango representativo de quesillo artesanal en Valencia/Carabobo.

## 4. Próxima validación de mercado

Para una muestra útil, registrar al menos 8–12 ofertas de productores distintos y separar:
- quesillo tradicional completo (por ejemplo 500 g, 750 g, 1 kg);
- sabores especiales;
- porciones individuales;
- venta por encargo y para eventos;
- precio al consumidor vs precio para cafeterías/comercios.

Por oferta: fecha, municipio/sector, vendedor, peso neto, precio, empaque, entrega, anticipación, disponibilidad, método de conservación, evidencia de publicación y si el precio fue confirmado directamente. No contactar vendedores en nombre del usuario sin autorización.

## 5. Consecuencia para el modelo financiero

La app debe permitir un precio de referencia con fecha y estado, no fijar automáticamente el precio de venta usando una sola publicación. Para cada receta se calculará el costo real por kg vendible y unidad vendible; después se comparará con escenarios de precio (bajo/base/alto) y canal. El escenario bajo debe poder ser probado contra la referencia artesanal de US$10/kg sin asumir que sea un precio actual de Valencia.
