### Advertencias técnicas

- Los precios por litro son solo división aritmética del precio anunciado por el rendimiento anunciado; no son costos validados de producción.
- Confirmar cepas, uso para yogur firme/batido/bebible, dosis exacta por lote, vida útil, almacenamiento, transporte refrigerado/congelado, fecha de vencimiento, ficha técnica y soporte microbiológico.
- El cultivo debe seleccionarse por especificación del producto y proceso; no elegir solo por precio.
- Para lotes pequeños, una presentación para 50 o 500 L puede generar desperdicio si no puede fraccionarse y conservarse de forma válida. El costo útil puede ser muy superior al coste nominal.
- No usar un cultivo de quesos como sustituto automático de cultivo de yogur.

### Checklist técnico de envases

Antes de aceptar un envase se debe verificar:
1. Declaración o ficha de aptitud para contacto con alimentos.
2. Resistencia a la temperatura real del proceso (baño María/horneado para quesillo) y a enfriamiento.
3. Tipo de tapa, sello, hermeticidad, manipulación y posible migración de materiales.
4. Capacidad útil y peso neto que admite la receta, no solo capacidad nominal.
5. Precio por unidad utilizable con tapa/sello, flete, embalaje, roturas y MOQ.
6. Compatibilidad con refrigeración, apilado, transporte y etiqueta.
7. Muestra de prueba antes de comprar volumen.

## 4. Coste completo de empaque para el CPP

El SKU de empaque debe desglosarse en: recipiente + tapa + sello/foil + etiqueta + cuchara si aplica + caja/bolsa secundaria + flete prorrateado + pérdidas/defectos. El costo unitario de entrada se normaliza a unidad base y se incorpora al CPP tras recibir mercancía y comprobar cantidades.

Fórmula:
Costo por envase utilizable = (importe de recipientes + tapas + sellos + etiquetas + transporte + cargos atribuibles − descuentos) / unidades utilizables recibidas.

No usar capacidad nominal en cc como equivalencia exacta a gramos de producto sin comprobar densidad y llenado real.
